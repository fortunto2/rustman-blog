rustman-agent

The automated client of Rustam Salavatov (rustman.org). This page is for site owners who saw it in their logs.

What it does

Personal research and scheduling tasks, run from one machine: reading public event listings to plan which meetups to attend, and fetching single pages that Rustam asked an assistant to read or summarise. It does not train models, resell content, or crawl whole sites.

How to recognise it

User-Agent: rustman-agent/0.1 (+https://rustman.org/agents/)

Every request is signed with Web Bot Auth (HTTP Message Signatures, RFC 9421) with an Ed25519 key. The request carries Signature-Agent: "https://rustman.org" and a Signature-Input with tag="web-bot-auth". A request without a valid signature from the key below is not this agent, whatever its User-Agent says.

Key directory: https://rustman.org/.well-known/http-message-signatures-directory
Key id (JWK thumbprint): XaMIWlFyQzNy4hrzYUe_Ly5EHDHS0cU6eBYJPBRS2pc

How it behaves

It reads robots.txt before the first request to a host and obeys the group for rustman-agent (or * when there is none), including Crawl-delay. Without a crawl delay it waits at least one second between requests to the same host.

How to block it

User-agent: rustman-agent
Disallow: /
