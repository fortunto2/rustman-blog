# Live2Play

[Live2Play](https://live2play.superduperai.co) is a set of games for people who are already
in the same room — the phone is a prop, not the point. No accounts, no lobby codes, no
second device to pair.

The site and the [iOS app](https://apps.apple.com/app/apple-store/id6794370589) are one
product and share a single funnel: the same analytics id covers both, so a visit that turns
into an install is one line rather than two systems that have to be reconciled later.
